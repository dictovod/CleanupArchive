# CleanupArchive 1.2.1

Патч-релиз исправляет проблемы, обнаруженные в диагностическом запуске
версии 1.2.0.

## Исправлено

- Восстановлен повреждённый модуль очистки кэша эскизов и значков.
- Загрузка неполного или синтаксически повреждённого модуля теперь
  останавливает программу до запроса UAC и до любых операций очистки.
- Журналы отдельного запуска с `-WhatIf` действительно сохраняются;
  служебные строки `What if: Add Content` больше не попадают в консоль.
- Отказ доступа PowerShell теперь распознаётся как безопасный пропуск,
  даже если провайдер файловой системы обернул его в другой тип исключения.
- Активные журналы событий больше не отбрасываются только потому, что в них
  появились новые записи между предпросмотром и подтверждением.
- Недоступный отдельный канал Event Viewer считается безопасным пропуском,
  а не критическим сбоем всего запуска.

## Безопасные значения по умолчанию

- `CleanDefenderCache` добавлен как отдельная опция и выключен по умолчанию.
  CleanupArchive не отключает Defender и не меняет права защищённых файлов.
- `CleanEventLogs` выключен по умолчанию. Интерфейс и документация теперь
  прямо указывают, что `wevtutil cl` полностью удаляет события выбранного
  канала, а не только старые записи. Журнал Security всегда исключён.

Пользовательские журналы, HTML-отчёты и диагностические данные в релизный
архив не включаются.
